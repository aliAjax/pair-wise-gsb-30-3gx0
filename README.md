# 油品配送发运闭环

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原"油品配送计划"最小闭环基础上，扩成 **罐车 / 司机 / 配送单 / 到站回单** 联动的发运闭环，数据保存在浏览器 localStorage（键 `hxwlfront-19-oil-delivery`，带 `version: 2`，旧版数组数据自动迁移）。

## 业务规则

1. **建单选资源**：每张配送单选目标油站、油品（最多两种）、罐车、司机、装油日期与起止时段。
2. **占用与拦截（待发车 / 运输中均占用）**：
   - 同一罐车装油时段重叠 → 拦截；同一司机时段重叠 → 拦截；
   - 装油时段结束必须晚于开始；计划合计吨数不得超过车牌额定载重；
   - 只有隔仓数 ≥ 2 的罐车才能装两种油品，单隔仓装两种直接拦截；
   - 同单不允许重复油品。
3. **改时段先释放**：待发车订单支持"改时段/改派"，校验通过后原车牌/人员/时段占用先释放，再登记新占用，所有前后变化写入修订链。
4. **装油发车强校验 + 锁定**：点"装油发车"时按装油日期强校验罐车年检、危货运输证、司机驾驶证、从业资格证，任一过期/失效不得发车；发车后锁定车牌、司机、油品与吨数（锁存快照），运输中不可再改派。
5. **到站回单**：运输中点"到站回单"，按实际卸油量逐油品回写；实际与计划差异超过 ±2% 必须填写差异原因，否则不能确认。
6. **释放占用 + 原计划可查**：只有"到站确认"才把订单移出占用看板、释放罐车与司机；计划油品/吨数原值与实卸值同表展示，差异原因、确认时间一并留存。
7. **修订链**：创建、改派、装油发车、到站确认、数据迁移全程留痕，页面可展开查看。
8. **被挡操作提示**：顶部告警条固定展示 车牌、人员、时段、油品 以及每条"触发条件 + 具体说明"（如与哪张配送单冲突、哪本证件何时过期），刷新后订单/占用/回单/修订链仍一一对应。

## 页面

- **配送单**：建单/改派表单（实时预检冲突）、占用看板、配送单卡片（锁定信息、计划/实卸对比、差异、修订链、流转操作）、状态分布图。
- **罐车台账**：车牌、载重、隔仓数、年检/运输证有效期（已过期、30 日内到期高亮）、当前占用。
- **司机台账**：驾驶证、危货从业资格证有效期与当前占用。

种子数据中包含可直接演示的冲突与失效场景：鲁C·77812 年检已过期、鲁A·22086 危货运输证临近到期、李海峰资格证 2026-08-31 失效、赵立军驾驶证已过期。
