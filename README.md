# 油品配送计划

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 领域闭环校验：`npm run check:domain`

罐车、司机、装油时段、配送单与到站回单联动的发运闭环，数据保存在浏览器 localStorage，重载后订单、占用、回单和修订链仍一一对应。

## 发运闭环

1. **创建配送单**：选择罐车、司机、装油时段与油品吨数，创建即占用该车/该司机的时段。
2. **改时段**（仅待装油）：先释放原占用再占用新时段，新时段冲突则拦截并保留原占用。
3. **装油**：校验通过后锁定车牌、司机、油品、吨数；仅带隔仓的罐车可混装两种油品。
4. **发车**：人员/车辆时段重叠、证件失效或年检过期均不得发车。
5. **到站确认**：按实际卸油量回写生成回单并释放占用；差异超过 2% 必须记录原因，原计划值在回单与订单中继续可查。

所有被拦截的操作都会在页面顶部展示车牌、人员、时段、油品和具体触发条件，并保留拦截记录。
